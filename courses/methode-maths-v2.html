3

Le nombre de places

n est un entier positif : xⁿ est un produit de n facteurs x. Quand x devient x + h, tous les facteurs changent.

Développer : choisir x ou h dans chaque parenthèse, puis additionner tous les produits possibles.

Observer · 1 / 5

Combien de produits contiennent exactement un h ?

On choisit h à une place et x à toutes les autres.

La règle est devenue un dénombrement
(xⁿ)' = n · xⁿ⁻¹

n places pour h. À chaque place, les n − 1 autres facteurs donnent xⁿ⁻¹. Les termes avec plusieurs h tendent vers zéro après la division par h.

Pourquoi cela vaut aussi pour x négatif ou nul

Les longueurs du dessin demandent x > 0 et h > 0. Le développement algébrique est une identité pour tout x réel et tout h réel. Après division, h tend vers 0 des deux côtés, en restant non nul.

Pour n ≥ 2, le reste R(x,h) est un polynôme en h : pour x fixé, il reste borné près de 0. Donc hR(x,h) tend vers 0. Pour n = 1, le quotient vaut directement 1, et la dérivée de x est 1.

Une démonstration à votre rythme. Les curseurs et les repérages sont facultatifs.
